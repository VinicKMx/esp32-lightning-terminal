# Hardware

Initial target: ESP32-S3 development board.

Reference hardware should include:

- ESP32-S3 module;
- TFT or OLED display;
- buttons or rotary encoder;
- optional buzzer;
- status LED;
- USB power and programming;
- regulated power input;
- ESD protection;
- power protection;
- programming and debug access;
- test points;
- enclosure design.

Hardware artifacts belong in:

- `hardware/schematic`;
- `hardware/pcb`;
- `hardware/bom`;
- `hardware/enclosure`.

Bring-up documentation should capture board revision, flashing procedure, measured power behavior and known hardware limitations.
